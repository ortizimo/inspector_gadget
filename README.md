# inspector_gadget
script to find files commonly used in stenography
Here's another script I made to find and export to a separate folder all files commonly used in stenography. It also can work for law enforcement for finding CP.
1. move to your Linux OS
2. make executable (sudo chmod +x script_name)
3. move to /usr/local/bin (mv script /usr/local/bin)
4. use from any directory (now global CLI)
